# 高中中文口语素材周刊 · 教师工作台操作指南与交付说明

本文档面向一线语文与口语授课教师、教研组长及采编把关人员，详细说明如何使用**生产运行工作台（Production Workbench）**完成周刊的日常监测、周四截稿审阅、周五定版出刊与异常排查。

---

## 一、 产品定位与核心业务节拍

1. **产品定位**：
   - 本周刊为**高中中文口语表达训练资料**，旨在培养高中生“具体动作叙事复述能力”与“生活视角思辨立论能力”。
   - **严守边界**：周刊绝非英语课程，不可添加英语生词表或翻译练习；不可使用宏观政务会议通稿作为口语训练材料。
2. **生产业务节拍**：
   - **资料截止时间**：每周四 **20:00:00**（Asia/Shanghai 时区）
   - **截稿扫尾抓取**：每周四 **20:05:00**（自动补抓截稿前最后一波新发布）
   - **正式出刊发放**：每周五 **10:00:00**（交付课堂印刷与早读使用）
   - **回望考察窗口**：严格回望截止时间前连续 **7 天**（168 小时）的真实报道与评论；相邻常规期次首尾相接，杜绝换期号重复使用材料模拟连续出刊。

---

## 二、 工作台四大核心看板解读

访问工作台地址：`http://127.0.0.1:3002/workbench.html`（或后台守护运行端口）。

### 问题 ①：现在有没有在工作？（多任务独立运行健康度）
- **时评与事实报道采集 (launchd)**：macOS 系统级常驻守护，每天固定执行 2 次（**09:30、18:30**）加周四 **20:05** 截稿扫尾。低频轻量，机器无负担；
- **暖文与好事雷达 (Node.js 后台)**：独立执行好人好事与凡人微光故事挖掘（6 小时采集 / 20 分钟分析周期）；
- **选材分析与推荐引擎**：本地高中口语规则初筛与四档适用性实时聚类；
- **数据备份与隔离恢复**：每次备份自动在隔离目录（`/tmp/restore_test_*`）执行无害化还原验证，通过后标绿 `PASS`；异地备份客观标注为 `待配置 (缺少受控外部存储目标)`。

### 问题 ②：这一周收到了什么？（统一入库池）
- 汇聚全库 14 路权威信源与暖文雷达数据（当前 640+ 篇储备，230+ 篇完整正文）；
- 自动呈现：**重点推荐**篇数、**需教师特别复核**篇数、**待补充事实**篇数与**往期已用**沉底数。

### 问题 ③：下一期做到哪了？（业务流水线推进）
- 当前试发期次（**W39 首次试发件**，47 页）已定版发布，供课堂实测；
- 下期常规期次（**W40**）明确标示为【**等待计划时间（周内正常采集备料中）**】，周四 20:00 前绝不提前锁定未结束的资料窗口。

### 问题 ④：我要做什么？（教师行动指引）
- 提示教师当前所处时段的工作重点，周内日常无须人工盯梢，周四晚集中审阅。

## 三、 教师周内与周四截稿实操流程

```
[ 周一至周四 20:00 前 ]                [ 周四 20:00 截稿后 ]                     [ 周五 10:00 前 ]
后台自动采集、备份与初筛  ─────────►  教师进入工作台进行 4 档审阅与批注  ─────────►  定版确认并原子排版出刊
(launchd 每日 2 次轻量轮询)           (重点复核 S/A 级与敏感议题)                 (生成 47 页 PDF 与审阅站)
```

### 1. 日常怎么看（周一至周四下午）
- **看什么**：
  - 扫一眼问题 ① 卡片是否显示绿色【运行正常】；
  - 确认信源通道数量（14/14 正常）；
  - 确认数据备份卡片显示【隔离恢复测试通过 (PASS)】。
- **不需要看什么**：
  - 不需要逐条翻阅采集到的几百篇原始新闻；
  - 不需要担心电脑休眠（Mac 唤醒或开机后 launchd 守护进程会自动补跑最近一次错过的轮询）。

### 2. 周四截稿怎么审（周四 20:00 - 21:00）
周四 20:00 资料窗口正式截止。教师打开工作台【📚 本周候选材料池与教学选材工作区】：

#### 步骤一：审阅【⭐️ 重点推荐】（S/A 级）
1. 切换到【⭐️ 重点推荐】标签，列表按口语契合度得分从高到低排列；
2. 重点挑选：
   - **口语复述素材**：关注报道是否具备具体人物（如青年工匠、外卖骑手、轮椅考生）、动作细节（修路、救人、赛场拼搏）与场景转换；
   - **时评思辨素材**：关注议题是否贴近中学生生活经验（如校园手机管理、外卖柜收费、文旅NPC），是否具备正反双向立论空间；
3. 对满意的材料，直接点击右侧 `[✓ 保留]` 按钮；
4. 若希望调整推荐栏目，可点击 `[⇄ 改栏目]` 或进入抽屉指定为复述/评论/拆解。

#### 步骤二：审查【⚠️ 需教师特别复核】（敏感与争议议题）
1. 切换到【⚠️ 需教师特别复核】标签；
2. 系统已自动识别并拦截涉及成人婚姻隐私、艾滋病知情权、严重恶性案件等成人化话题（如《马上评｜保障艾滋病感染者配偶知情权》）；
3. **处置原则**：此类文章在高中课堂容易引发不适或偏离教学主旨，**默认建议点击 `[✗ 排除]` 剔除**；若教研组确有普法防艾专题研讨需求，教师需在抽屉内填写明确指导备注后方可入选。

#### 步骤三：检查【⏳ 待补事实】（纯元数据）
1. 切换到【⏳ 待补事实】标签；
2. 该分类下的文章缺少清洗正文（字数不足 200 字）。若发现极佳的新闻线索，需补充完整报道正文方可转入正式候选。

#### 步骤四：查看结构化理由与批注
- 点击任意文章标题或 `[📖 完整研读与批注]`，右侧展开抽屉；
- 抽屉清晰呈现五项结构化理由：
  - 📌 **核心事件**：一句话概括发生了什么；
  - 🎙️ **口语适配**：为何适合高中生口语复述或辩论；
  - 🏷️ **建议栏目**：推荐归入的分册与题型；
  - ⚠️ **教学顾虑与风险警示**：潜在争议点提醒；
  - 📑 **核心论据与细节**：原文核心事实或论点摘录；
- 教师可在抽屉下方输入指导批注并点击 `[💾 保存教师审阅意见]`，数据永久保存在 `data/teacher_feedback.json`，刷新不丢失，优先于算法排序。

## 四、 周五发放怎么出（定版与出刊交付）

周五上午 10:00 前，采编团队或 Agent 根据教师保留意见生成正文并进入发布流程：

1. **采编入刊配比**（共 21 篇）：
   - 第 1 分册（口语复述）：9 篇（配 9 幅三格/四格动作叙事插画）
   - 第 2 分册（时评思辨）：6 篇（包含核心立论、中学生视角与正反论辩）
   - 第 3 分册（原文拆解与积累）：6 篇（精选语言表达典范句段）
2. **执行发布门禁校验与原子排版**：
   在终端执行：
   ```bash
   python3 publishing/weekly_runner.py build
   ```
   **门禁硬约束（红灯中断原则）**：
   - ✅ **信源原段连续匹配校验**：周刊引用的所有事实片段必须在本地 raw/ 快照中 100% 连续逐字匹配，杜绝凭空捏造事实；
   - ✅ **47 物理页数守恒**：版面必须严格控制在 47 页，任何版面溢出或页码退化立即拦截；
   - ✅ **PDF 与静态审阅站同步产出**：输出合订本及三部分册 PDF，同步更新审阅站。
3. **定版分发**：
   - 教师可在工作台顶部直接点击 `[📥 下载试发件 PDF (47页)]` 获取印刷版文件；
   - 点击 `[🌐 审阅站]` 在浏览器中查验每一页高保真排版效果。

## 五、 异常排查与自查命令手册

| 异常现象 | 可能原因 | 教师 / 运维排查命令 | 预期正常表现 |
| :--- | :--- | :--- | :--- |
| **Q1 显示“采集延后”或“异常”** | 信源接口临时超时或网络抖动 | 查看抓取日志：<br>`tail -n 50 scripts/launchd_fetch.log`<br>查看运行状态：<br>`cat data/fetch_state.json` | `status: "success"`，`failed_sources_count: 0` |
| **信源需要立刻更新测试** | 刚进入周四截稿点想立即拉取最新报道 | 在工作台点击顶部 `[⚡ 立即执行采集测试]` 或在终端执行：<br>`python3 scripts/fetch_commentaries.py` | 14 路信源全部返回 200，并解析保存正文 |
| **数据备份需要手动触发** | 准备大版本更新或交付前完整备份 | 在终端执行：<br>`python3 scripts/backup_data.py --backup` | 生成 `weekly_data_backup_*.tar.gz`，输出 SHA256 与 `PASS` |
| **验证备份包能否真正恢复** | 验证归档文件完整性（隔离演练） | 在终端执行：<br>`python3 scripts/backup_data.py --test-restore backups/<文件名>.tar.gz` | 输出 `✅ 隔离恢复测试完全通过！` |
| **工作台服务意外中断** | Node.js 进程退出 | 检查并重新启动工作台：<br>`PORT=3002 node aggr-site/server.js` | 终端输出 `[aggr-site] 聚合站点已启动: http://127.0.0.1:3002` |
| **自动化测试回归验证** | 验证全流水线与教学推荐逻辑 | 在终端执行：<br>`PYTHONPATH=publishing:scripts python3 -m unittest discover -s publishing/tests` | `Ran 53 tests ... OK` 全部测试绿灯通过 |
