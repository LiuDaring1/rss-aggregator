## 三、S0 安全与只读模式验收基线

1. **写保护**：Node 站点在 `AGGR_READONLY=on` 模式下，对任何写入请求（feedback, collect, repair, rebuild, analyze 等）一律返回 403/503，不修改本地 `db.json`。
2. **离线保护**：在 `AGGR_OFFLINE=on` 模式下，GET `/api/health` 不向外网发请求，GET `/api/topics` 不调用 GLM API。
3. **数据原子性与损坏保护**：`store.js` 严禁在 JSON 解析失败时静默覆盖为空库，必须阻断并报错，单写者原子写入。
4. **Git 与凭据隔离**：`references/teaching-private/` 严禁入库；`agent-sync.sh` 增加暂存内容扫描与强安全校验。
