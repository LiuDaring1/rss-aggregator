## 1. 项目定位

把「微信公众号文章」+「各大媒体评论/新闻频道的 RSS」聚合到一个网页里，
按时间流浏览，形成自己的信息订阅体系。

三个服务协同工作：

| 服务 | 端口 | 作用 | 代码来源 |
| ---- | ---- | ---- | -------- |
| **we-mp-rss** | 8001 | 微信公众号聚合：扫码授权 → 订阅公众号 → 生成 RSS | 上游 [rachelos/we-mp-rss](https://github.com/rachelos/we-mp-rss)，本机适配 |
| **RSSHub** | 1200 | 把各家媒体站点转成 RSS（含 5 条自研路由） | 上游 [DIYgod/RSSHub](https://github.com/DIYgod/RSSHub) + 自研路由 |
| **aggr-site** | 3000 | 自研聚合网页：抓取所有源 → 统一解析 → 时间流展示 | **100% 自研**（非 git 仓库） |

数据流：

```
微信(扫码授权) ──> we-mp-rss:8001 ──/rss/{feed_id}/api──┐
                                                        ├──> aggr-site:3000 (统一抓取/解析/展示)
各媒体站点 ──────> RSSHub:1200 ──/路由──────────────────┘
                                                        └──> 浏览器 http://127.0.0.1:3000
```

## 6. 接手开发须知（重要）

1. **git 边界**：`rsshub/` 与 `we-mp-rss/` 是各自独立的 git 仓库
   （`rsshub` 的 origin 即上游，`we-mp-rss` 的 origin 是 fork、upstream 是原作者）。
   `aggr-site/` 与根目录**不是** git 仓库。改动前先 `git status` 确认工作区干净。
2. **don't 提交敏感文件**：`we-mp-rss/config.yaml`、`we-mp-rss/data/`（含微信授权
   wx.lic 与 SQLite 数据库）、任何 cookie/token/.env 都不要入库、不要打包进分发包。
   package.sh 已默认排除 `data/`。
3. **改 RSSHub 路由**：dev 模式（tsx watch）热重载，改完 `lib/routes/...` 立即生效，
   无需重启；正式部署可 `pnpm build && pnpm start`。
4. **改聚合站**：`server.js` 与 `public/` 改动后需重启 `node server.js`；
   `sources.json` 只需刷新页面。
5. **we-mp-rss 上游跟进**：合并上游前先 `git fetch upstream`，当前本机未跟进 vs 上游的
   `1.5.3` 之后的改动；升级依赖用 `requirements-314.txt`（Python 3.14 无 pydantic/
   pillow 等预编译包，故放开版本锁定）。
6. **Playwright 内核**：已装在 `~/Library/Caches/ms-playwright`（chromium + webkit），
   换机器需重新 `playwright install --with-deps`。
7. **代理直连（重要）**：本机若开全局代理（如 Clash `127.0.0.1:7897`），其出口访问
   国内媒体站会被源站掐断 TLS。RSSHub 与聚合站（Node）不读代理环境变量、始终直连，
   **勿给 RSSHub 配 `PROXY_URI`**；we-mp-rss 是 Python（会读代理变量），已在
   `start-local.sh` 里 unset 全部代理变量强制直连。三服务与全局代理可长期共存。

## 8. 源码包说明

`package.sh` 会生成 `RSS订阅-源码包-<日期>.tar.gz`，**只含源码与配置模板**，
已排除：`node_modules/`、`.venv/`、`data/`（敏感授权数据）、日志、`.git/`、
`__pycache__/`、`.npm-cache/`、`.pipcache/`。

接手方拿到包后：
1. 解压并 `cd RSS订阅`；
2. 重新安装依赖：
   - `rsshub`：`pnpm install`（会重建 node_modules）
   - `aggr-site`：`cd aggr-site && pnpm install`
   - `we-mp-rss`：`.venv/bin/pip install -r requirements-314.txt`（py3.14）或
     用 `python3 -m venv .venv` 重建后安装
3. we-mp-rss 的 `config.yaml` / `data/` 需从原目录复制（含授权状态）；
4. `./start-all.sh` 启动后访问 http://127.0.0.1:3000 。
