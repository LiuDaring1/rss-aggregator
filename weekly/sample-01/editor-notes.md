## 一、选了哪些材料，为什么

**完整加工（主体，3 篇）**——刻意选择三种不同形态的暖事件，检验三种不同的加工路线：

| 篇目 | 形态 | 检验的加工方式 |
| ---- | ---- | ---- |
| 职校生修家电 | 人物身份 × 行动方式 × 现实需求结合得很好的事件 | 训练"身份—需求"对接式立意（技能/适老/回馈三条线） |
| 八旬老人送盲人邻居 | 故事清楚、细节具体的普通暖事 | 训练"日常陪伴型"范本：靠排班表、台风天、瓜子等细节支撑，不用牺牲叙事 |
| 单脚鞋银行 | 有真实矛盾（需求消失）的公益转型故事 | 训练"矛盾—回应"式范本：先摆数字困境再立观点，避免单向赞美 |

**新闻复述（5 则）**：王植兴（理智施救）、楚亮（凡人善举 + 求点赞）、陈大爷（最小善举）、魏治立（无声示警）、德哥（长期值守）。与 3 篇主体不重复、不全是救人题材：既有惊险救援，也有盖塑料布这类"两分钟小事"。

**评论拆解（1 处）**：红星评论《让老师身后有"盾"》。选它是因为论证层次清楚（判断→推进→解释→办法），且"舆论比程序快""护师不等于护短"两句可直接迁移到口语；话题（师生、家校）贴近高中生生活。未选暖闻类评论，是为检验"非暖话题"的拆解是否同样可用——请老师重点判断这一取向。

**积累页**：全部取自本期已出现的 9 件事 + 1 篇评论，未另配名言。

## 五、需要老师判断的问题（3 个）

1. **范本口吻**：三篇范本都按"观点先行、层次清楚、结尾回扣"来写，但口吻偏"成熟"，学生直接背会不会不像自己的话？哪一篇最接近学生该有的样子，可作为今后范本的基准？
2. **参考复述的"满度"**：复述栏目的参考复述写得比较完整，学生可能照背而不自己组织。正式版是否要把参考复述后移到页面另一面（先遮后看），还是改写成"只给框架"的半成品？
3. **评论选材取向**：本期选的是批评性时评（师生家校）而非暖闻评论，训练价值更强但调性与"暖事件周刊"不同。以后每期是固定一篇批评性时评，还是暖闻评论与批评性时评轮换？
