# 口语素材周刊：rev.4 学生版修订任务书 v0.5

**对象：**在 `weekly/sample-01-rev3/` 的实际成品上修订，输出 `weekly/sample-01-rev4/`；保留全部旧版，不覆盖学生原稿。

**状态：**依据教师最新逐页反馈形成的本轮执行要求。文末示范是编辑提出的教学呈现样例，不是教师已定稿的范文，也不是本期新增新闻。

**使用方式：**这是一份合并后的完整规格，替代 v0.4.1 中的冲突要求。不需要教师再把几轮聊天和任务书逐条拼接。开始时读取现有正文、排版脚本、教师备注及可用原文；只做刊例修订，不重新设计雷达、课程或App。

## 1. 本轮核心：把教学讲解展开，把学生页面做清爽

三个一级板块不变：**复述、评论、原文拆解与积累**。

- 复述：约5—6则社会热点，约3则暖文／正向社会生活材料；每题材料页＋提示页，参考答案集中在本模块末尾。
- 评论：从上述复述中选约3则热点和3则正向材料，保持同题对应；**每题明确安排三页**：问题页、观点与推演页、口语范本与拆解页。
- 原文拆解与积累：继续从近期评论中独立选完整好段，约6—7个学习单元。保留本轮已选得好的片段，不因换版本全部重选；数据溯源片段按第6节处理。

核心读者是社会观察和独立思考经验较少的高中生。编辑不能把“给有经验的教师看得懂的提纲”，当成“学生自己读得懂的讲解”。

**两分钟限制属于口语范本，不属于前面的教学讲解。**范本应当精练，推演与拆解应当讲清中间过程；不要为了凑一页，把后两者压成几个抽象词。

不增加学生必须执行的日程、打卡、模考和自评。纸面内容支持阅读、思考、熟读、背诵、复述；不假定学生会严格完成每一道问题。

### 本轮明确替换的旧做法

| 旧做法 | 新做法 |
| --- | --- |
| 把媒体评论压缩后当作新闻材料 | 评论提供选题线索；复述材料重建新闻事实，不提前放入作者的完整观点和原因分析 |
| 提示页规定“先关键词，再导图，再插画” | 三种辅助并行、任选，不是三步流程 |
| 实线框放答案，虚线框少量留空 | 保留主题与分类标签；待组织的内容节点统一为虚线大空框，不混排已经填好的同级答案框 |
| 每题固定三个思考问题 | 围绕具体材料有层次地追问，数量由内容决定，不固定三个、不为填满页面硬凑 |
| 思考一页，全部答案挤在另一页 | 评论每题三页，观点与推演有独立整页 |
| 原文学习用“可背＋用位＋抽象使用说明” | 区分“值得记住的表达”和“可以借鉴的讲法”，删除“用位”，补真实写成的口语示范 |
| 漂亮的栏目说明框反复出现 | 学生版只留内容与少量必要学习提示；制作说明移到教师备注 |

## 2. 学生版外观：删掉制作说明，保留必要内容

保留教师认可的竖排目录、整洁黑白版式、大字材料页与模块分册。

封面只保留刊名、自然期号或日期及必要署名。去掉长篇栏目介绍、版本号、任务规范、完成状态、每题操作流程等内容。目录直接使用题目和页码，不用“一句话说明”列，不改回复杂表格。

三个板块开头不再放“与复述同一批材料”“独立精选近期完整段落”等黑框／矩形说明。保留板块标题后直接进入内容。

提示页也不写“先用……再用……”的流程。只保留“关键词”“思维导图”“插画”等清楚标题，至多一条确实必要的短提示。

“取舍”“依据任务书”“模型借鉴路径”“未实测”等制作信息放教师备注。来源、真实日期、必要的原文出处仍然保留。

不要为了显得活泼而使用大片底色、细密花纹或低龄卡通。阅读区保持整洁，变化主要来自图示、插画、字号层次和留白。

## 3. 复述：材料必须给学生留下自己评论的空间

### 3.1 先解决“国产动画”这道题的材料性质

当前“国产动画的中国脸”不是只难在词语，而是已经压进了媒体作者的审美评价、原因分析和结论。不能继续把这篇短评论当作事实输入，让学生复述完再评论相同结论。

处理原则：
- 动画题材本身不禁止。若已有真实报道能提供具体角色、创作做法、当事人介绍、公开反响和清楚变化，可以重新整理成事实材料；评论作者对变化原因的解释留到第二板块。
- 若拿掉作者的分析后，剩余信息不足以构成可读、可讲的材料，本轮直接换为已有资料库中事实充足的事件或现象题，不继续加术语或笼统背景撑字数。
- 不因保留题材而把“允许不完美”“技术—国潮—市场三条件”等观点原样放在材料页。题目也不要预先宣布全部评价结论。
- 替换或重编后，同步更新对应评论、关键词、导图、答案、目录、页码和插画需求；不复用依赖旧事实的部分。

此要求是“事实材料与评论分开”，不是“只有个人善举才能复述”。文化生活、青年生活、公共服务变化仍然可以使用。

### 3.2 其余材料与参考复述

材料页写清对象、背景、经过、关键细节、变化和回应。保留让学生认识社会所必需的背景，不是把两行摘要放大到一页，也不靠连续评论、设问和情绪词填长。

可以使用评论中引用的可核对新闻事实，不因为它来自评论页面就一律排除；关键在于提取的是事实，不是作者已经给出的立意和推论。能够取得原始报道时优先对照。

当事人或有关方面的说法应当说明归属，不能把有争议的说法直接变成确定事实。补充信息来自实际材料，不编对话、心理、行为和结果。旧事件保持真实时间，不把转载／评论时间改成事发时间。

参考复述以准确讲清事情为主体，展示合理取舍与重新组织。允许最后少量自然点题，不让后半段变成批评、倡议或宏观结论。审查原来保留的参考稿，不是只改材料页。

全部参考答案放在复述末尾。每页约三则，按实际篇幅调整，不以缩小字体强挤。题号、标题、材料页码一致；参考要点接受准确的同义概括，不要求逐字复刻。Markdown也按实际教学顺序组织：先全部题，再集中参考，不在每题下面提前铺出答案。

## 4. 提示页：三种并行辅助＋统一留空导图＋真实版面修复

### 4.1 三种辅助没有先后流程

- 关键词网络帮助想起重要信息。
- 思维导图帮助自己归类、组织信息和关系。
- 插画帮助回忆场景。

学生可以任选，也可以结合使用；不要求按①②③顺序练三遍。不把“并行”做成一段新的黑框解释，只需排版和简短栏目名体现即可。

### 4.2 思维导图统一成可补写的信息树

保留一个中心主题，以及与材料相适应的主枝、必要的次级分类。主题和分枝名称可用普通文字，不必装进实线矩形。

**需要学生组织和写入的内容节点，统一使用同一种虚线框。**不再混排“已填好的实线答案框”与“少数虚线题目框”。叶节点内不直接印完整事实答案。

这不等于把主题、分枝和关系全部擦掉：例如“人物处境”“行动与反馈”“各方回应”“结果变化”等分类线索仍可保留；具体取舍服从材料，不强套同一套枝名。空框里最多放很短的提示，如“主要困难”“最初尝试”“关键变化”，不要写长问句占掉书写区。

补写的单位是一项完整信息、一种做法、一组结果或一小组相关内容，不是一个词的一两个字。给足可以写短语、分点或简短句子的实际空间。

导图的主枝要体现归属，不重复摆放同一事实。行动过程可作为某一组分枝，不把整图只画成时间流程。关键词网络不逐字提供导图的整套答案。

先依据定稿材料生成完整内容树，后台保留完整版；再输出学生留空版及集中答案中的要点参照。每个待补内容在本题材料里都有依据。测试时把参照要点逐项放回对应节点，检查语义和归属，不只检查字数。

### 4.3 修复缺边、刺线与溢出

当前代码存在需要核查的具体情况：`gen_net()` 将部分节点中心固定在画布两侧，而框宽随文字长度增长，长框可能伸出SVG画布；`gen_tree()` 的若干连线采用固定坐标或只连到组的中线，未完整表达父节点到各子节点的关系。请以实际导出结果确认并修复，不只修改一张示例图。

要求：
- 节点、文字、描边都在画布安全区内，不能以overflow:hidden掩盖越界。
- 连线准确接到父子节点边界，不穿过文字、不悬空刺出、不把两组错连。
- 长文字换行、节点宽高和画布尺寸彼此匹配，不靠截字解决。
- 所有题都渲染成实际PDF页检查，尤其查看左右边缘、根节点较长、子节点较多的情况。
- 按实际打印尺寸检查字能否看清、空框能否写入；不要只看源码和浏览器缩略图。

### 4.4 插画仍按简单转交流程

保留 `illustration-briefs.md`：题号、定稿事实、画面需求、不能新增的情节、完整提示词、图片编号与比例齐全。材料改变后同步修改需求，不把过时提示词拿去出图。

默认流程不变：Agent写需求 → 教师转交当前对话生成图 → 图片回传 → Agent嵌入与导出。不开发图片自动化平台，不因等待插画停掉文字修订，也不以图标冒充真实插画。

画风：白底黑线、报刊式简笔叙事插画，线条适中，主体和关键动作清楚，适量留白；避免照片感、密排线、大黑块、繁杂背景和低龄比例。示意图不添加影响事件含义的新行动、原话或结果。

## 5. 评论：每题三页，讲解面向缺乏经验的高中生

### 第1页：读材料，打开思考

以题目、对应材料页码和简短事实回顾开篇，随后是具体问题与适量记录空间；不显示观点答案和范本。不再每题统一三个问题。

问题从学生可以观察、回忆、比较的地方进入，再逐步追问感觉、关系、影响、原因和其他解释。可以是五六个、七八个，也可以更少，取决于材料；这些数字不是配额。问题可以形成几组，也可以连续展开，不做长问卷，不要求学生逐题写满。

问题要明确对象：谁的变化？材料哪两处细节？比较哪个具体方面？不能只有“靠的是五官还是别的什么”“这给我们什么启示”这样的悬空问法。

联系自身经历是入口，不是资格考试。没有看过某部动画、没有去过某地的学生，仍能依靠材料回答主要问题。不要借提问假定未被报道的过去经历或社会共识。

对动画题，教师提出的方向可用于检查问题是否具体：看过哪些角色；旧造型与新造型各有什么可描述特点；所谓相似具体相似在哪；对辨认人物、理解性格有什么影响；某个具体新角色给自己的感受如何；它受到欢迎可能有哪些原因。这只是提问方向，不能替代重建中性的事实材料。

问题与观点相辅相成，不一一配答案；不让每题都出现相同数量、相同措辞的三组模板。

### 第2页：观点参考＋一步步讲清怎么想到

本页不是“多放几个抽象判断”。先列有区别的具体观点，再选择最值得学习的一到两条充分讲解，其他角度说明到能理解即可。不要把所有观点都塞进后面的两分钟范本。

讲解按真实课堂的耐心程度组织：
1. 指出材料里究竟哪一句、哪两个事实值得放在一起看。
2. 先说明一个学生容易有的直观理解，指出它还没有解释什么。
3. 借熟悉的经验、具体比较或明确假设，让学生感到问题在哪里。
4. 把缺少的中间环节说出来：为什么这件事会影响这个人、这项做法怎样起作用、这两个情况有什么相通或不同。
5. 给出从这里形成的判断；必要时轻点它不能推出什么，不让整页充满术语和免责声明。

这是编辑内部检查线索，不是每题必须在学生页印五个步骤。最终写成容易跟读的短段讲解，适当用小标题、原句回指和停顿留白。

不能用“档案属性→信息差→信任”三个词替代解释。需要把“档案为什么会被继续使用、接下来可能影响什么、为何值得在意”讲清。也不能仅增加字数、换形容词或重复观点冒充推演。

允许合理分析、换位思考、生活经验和明确的设想，不把分析限制为新闻复述；但不能给当事人补未经报道的经历、心理、原话和行为。

**这页可以比范本更细。学生要通过讲解学会思考，随后才在范本里看到怎样把这些思考收束成两分钟。**

### 第3页：口语范本＋具体拆解

范本执行已有教法，不因扩页而变长成课堂讲演：
- 第一处表达直接给出具体判断，不重讲完整材料。
- 开头的关联词表达真实关系，不先设一个不存在的靶子。
- 两个主体段，各自先亮出小观点，再解释、推演，使用必要的材料并回扣；两段有区别但共同服务开头。
- 独立结尾收回主线；不让后三篇又变成三段短文，不靠喊口号补尾。
- 语言自然、成熟、可说；允许修辞和好句，不强迫模仿助手的生涩校准稿。

范本后优先展示全文主线，再细拆一处最值得学的主体段：这句话提出什么、下一句话为何接得上、例子怎样支撑观点、最后如何收回。也可分析一处精准措辞，不把每句都贴满标签。

拆解必须检查范本，不替它找借口。“用了对比所以深刻”“加了可能所以稳妥”“提到宏观概念所以升华”都不是有效拆解。

三页保持这个功能分工。优先用合理留白和字号安排完整内容，不能因原模板只有两页就缩字号、截段落或把推演压回百字概述。需要小范围调整时在教师备注说明，不擅自取消教师明确要求的独立讲解页。

### 有参考评论与无参考评论

有全文评论可借鉴：保留作者有效的观点、事实、原因分析、例子和语言，但按上述口语范式重组，不照搬媒体导语和篇章顺序。注明借鉴只放教师备注，学生看到的是完整学习内容。

无参考评论：使用教师讲过的细节、关系、追问、经验和视角方法，先把论证想清再成稿。不能把暖评写成故事加赞美，也不默认所有题第二段都必须讲制度托举。

可使用其他实际可用的写作模型，不建设新的模型系统，不声称使用未实际调用的模型。审稿和拆解必须以最终范本为对象，不能只在备注里写“已整段重写”。

## 6. 原文拆解与积累：细讲方法，区分记忆与借鉴，给完整的口语示范

### 6.1 保留好选段，调整不适合当前学生的选段

继续独立精选近期评论，保持完整自然段或必要的连续段落、新闻由头、作者问题、真实出处。不是第二板块的参考文献附录，也不强制所有选文同题。

教师已肯定类比、细节对照、幸存者偏差等片段的学习方向，可以保留并深化。**本轮撤换以宿舍面积数字比较为主要教学价值的“数据溯源”单元**：不是否定数字和背景分析的价值，而是当前学生无法临场寻找、记忆和调用大量专门数据，不把这一任务作为本期主要训练。

允许材料内少量重要、易理解的数字，也允许有数字的优秀原文；不由此推导为“评论不能有数据”。如果另有同篇非数据密集、确实适用的段落，可以重新选段，但必须真正改变本单元的学习目标，不只把标题换成“原因分析”。

### 6.2 学生能看见原文，也能跟着解释读懂

原文完整呈现，删节如实标示。不得将不相邻的段落伪装为连续原文；不得将AI改写标为作者原句。明确已取得的原文、版本与来源，来源未确认先处理，不靠加引号冒充核验。

拆解比当前更细：可以用少量句号序号回指原句，解释它在做什么、为何这样接、关键相似点或对比维度在哪里、一个词为什么合适。不要只宣布“这是类比”“这是列举”。

类比重点讲两件事共享什么关系，以及类比可以支持到哪一步；细节对照重点讲当事人的哪些真实信息使形象更具体；幸存者偏差要用可懂的场景说明自己看到了谁、没看到谁。

避免把某篇有效做法变成所有文章的要求：有真实犹豫可以分析，不规定善举一定要先犹豫；有数据可以解释，不规定所有评论必须补数据；引用媒体原文也不自动证明它所有结论都成立。

### 6.3 删除“用位”，不把一切都叫“可背”

以后使用清楚的学生语言，按实际价值选择以下内容，不要求每单元三个小栏都齐全：

- **值得记住的表达**：真正有语言价值的措辞、金句、完整句段；标出具体范围及意思。不是只让学生背功能连接语，也不因为某句话是当事人原话就默认必须逐字记住。
- **可以借鉴的讲法**：类比、对照、列举、展开顺序、句式组织等。通过具体例子说明，让学生学会说，不要求背一张“A像B”的空模板。
- **换个话题，可以这样说**：给一个具体题意／场景，加上一段已经写成、可以直接开口的示范。不能只写“找个旧例、讲出共识、回到判断”。

“用位”字段直接删除，不换一个同样费解的缩写。确实需要说明使用位置时，自然写成“谈到……时，可以接着这样说”，再给成品段落。

人物原话可以作为案例中的真实细节，但本期学习重点由教师要求决定：例如骑手犹豫那段，重点是如何把顾虑、选择和他人回应讲具体，不是要求背下整段采访逐字稿。

### 6.4 示范必须真正说出来

每个单元至少给一个有内容的口语应用实例；可以换话题，也可以用本段素材演示压缩、改说和接回观点，不强行跨题。

示范要包含：准备说明的一点、实际展开的例子或理由、回到判断的一句话。使用真实案例时保留事实依据；采用设想时明确写“设想”“假如”，不能给学生编造亲身经历或未核实历史。

全部面向口语表达：写“可以这样说”“试着复述”，不继续要求学生“写一篇”“照着写”。分析原媒体作者时，使用“作者这样写”当然正常，不做机械替换。

示范后可以留一句简单鼓励：例如“试着不用原句，把这段相似关系讲清楚”。这是可用的练习邀请，不变成新的必做考核。

## 7. AI陪练：简化操作提示，不改变听众角色

使用随附 v0.5 文本。教师明确删去“看不清图片就询问”和“没听清就先确认”这两类流程说明，不在学生版反复强调。

只保留一个初始确认，然后等待复述结束；结束后一句具体肯定、最重要的一两个问题、针对问题的简短示范。不要在倾听阶段插话，也不要将全部参考稿重新说一遍。

提示词中的依据边界仍然保留：只依材料和实际表达，不补事实，不强迫背原文，不把复述改成评论。删去冗余说明，不等于制作端可以声称所有产品的识图、语音识别和等待行为已经保证无误。

完整指令提供可复制txt，并在一处合适位置印出；材料页脚可以只留一句简短使用提示。不要每题重复整段指令。未做过拍照—通话测试，教师备注如实标记，不能自行写“已验证稳定”。

## 8. 内容与版面同步验收，不再只修修改说明

先完成材料和核心正文，再据此更新观点、拆解、导图、答案和图片需求。不把新要求只写进教师备注，旧范本原封不动。

已经指出的问题回归检查：
- 复述材料是否仍然在提前讲完整评论；参考稿是否又加进大量独立评论。
- 病历稿未经材料支持的医疗恢复时长是否删除；原文限定、责任主体和时间是否准确。
- 葫芦稿不能由一块提醒牌直接证明生活未受打扰，也不能把不收费写成善意成立的必要条件。
- 救人稿不能将成功归功于一个“松手”动作；不把个案包装为未成年人应模仿的救援教程。
- 示警稿不再用不存在的“别人会放弃”作陪衬，也不让“嗓门”“不麻烦人”代替对有效行动的解释。
- 拆解不再教“有犹豫才可信”“只要加可能就稳妥”，不把比喻自动当观点。

完成后实际渲染PDF并查看所有页面，重点是：网络图四边、导图父子连线、空框面积、阅读字号、评论三页对应、第三板块示范是否完整、目录和页码、集中答案定位。不能只用“代码运行成功”代替看版。

审阅PDF与学生Markdown必须内容一致；文字版也不要把答案提前插回题目后。封面说明框、模块说明框和制作语句应在最终导出中消失，不只是修改Markdown。

本轮文字成稿后，插画未回传可以交审阅稿及更新后的需求包，这是正常阶段性交付；插画仍沿用已约定的简单转交流程。

## 9. 交付与范围

输出到 `weekly/sample-01-rev4/`，至少包括：
- `sample.md`：学生正文，按真实学习顺序组织；
- `sample.pdf` 及三模块分册，图片未回传时标为审阅稿；

- `ai-retelling-prompt.txt`；

- `change-summary.md`：说明本轮真实修改位置，少写自我评价。

总体页数随评论三页及必要解释自然变化，不再强行压回39页。保持模块分册可单独打印；不靠缩字体获得表面紧凑，也不故意留大块空白显示“有练习”。

# 附录A：教学呈现尺度示例（编辑示意，非本期新题或教师定稿）

以下用已有课堂题说明“讲得细、示范完整”是什么程度。Agent要学习呈现方式，不要求所有题照抄同一句型。这里的材料来自教师提供的课堂记录；例段为本次编辑新写，不冒充原文作者或学生原话。

## A1. 问题要让学生能够一步步进入材料

已给材料：学校为唯一一名毕业生举行毕业典礼。

可用的问题：
1. 材料中的“只有一个人”和“仍然举行典礼”，为什么值得放在一起看？
2. 如果只按参加人数衡量活动，给一个人办典礼可能会被觉得哪里“不划算”？这里是假设一种看法，不代表学校真的有过取消计划。
3. 换到毕业生的位置，同届人数少，会让自己的毕业变得不重要吗？为什么？
4. 回想一次与你有关的毕业、领奖或告别：你在意的只是场面大小，还是有人认真记得你的经历？没有类似经历也可以从材料设想。
5. “学校很重视学生”还比较笼统。它在这件事里具体尊重了什么？
6. 除了看见这一名学生，这样的选择还能怎样帮助我们理解学校与学生的关系？

不要求学生全部作答。这些问题只是打开事实、经验与关系的入口，参考页可以把其中几条合起来形成一个观点。

## A2. 推演不是三个箭头，要把缺少的一步讲出来

先别急着用“温暖”作结论。把材料中两个信息放在一起：只有一名毕业生，学校仍然为他举行典礼。为什么这个组合会让人注意？

如果只看参加人数，为一个人准备一场活动，好像花了不少工夫，却只服务了一位同学。这是在从组织活动是否省事的角度看。

可换到这名学生的位置，他完成了一段学习，即将离开学校。同届人数少，并不会让他的付出少一分，也不会让这次告别变得不重要。同样是毕业，他也有理由期待被认真祝福。

现在再回到学校的选择，就能比“学校很温暖”多说明一点：学校没有仅按人数多少决定是否认真对待，而是看到了这个学生的经历本身。于是可以形成这样的判断：**参加典礼的人可以少，一个人的成长不该因此被轻轻带过。**

这里并没有证明典礼越大越好。真正起作用的，是学校怎样对待这个具体的人。这样把理由说清楚，观点才不只是一个赞美词。

## A3. 类比的“使用示例”应是一段能直接说的话

示例话题：讨论手机在校园中的使用，怎样避免只凭“工具好／工具坏”下结论。

下面采用假设性的课堂场景演示类比，不是在叙述某地真实校规，也不声称所有学校都经历过“禁止计算器到允许使用”的历史：

> 讨论手机在校园里能不能用，可以先想想一节课里的计算器。假如这节课练的是心算，直接按出答案，练习的意义就少了；假如大家已经掌握运算方法，这节课重点是分析一组数据，计算器又可能帮我们省掉重复计算的时间。同一个工具，合不合适，要看学习任务。手机也需要这样具体地讨论：查资料和刷视频不是一回事，课上与课后也不能混在一起。两种工具并不完全相同，但它们都提醒我们，把使用场景、目的和边界说清楚，比一句“有用”或“有害”更有解释力。

这段借鉴的是“把另一个场景讲具体，说明相似关系，再回到当前问题”。没有靠一句“道理相通”代替解释，也没有因此宣布手机应不受限制进入校园。

学生可以试着换自己的语言讲清：两种工具的共同点是什么，这个共同点能说明什么。

## A4. 不把人物原话当成必须背的采访稿

以刊例已选的骑手扶老人片段为基础，若最终核对的报道仍支持相关事实，可以整理为下面的口语示范。它只示范如何讲述已报道的顾虑、选择和回应，不要求学生仿造另一段“犹豫”：

> 评价一次善举，也可以把人物真实的顾虑讲出来。材料里的骑手承认，自己曾担心帮助老人会不会惹来麻烦，但还是决定上前；到了医院，老人又明确说是自己摔倒的，对方是好心。这两处细节放在一起，人物就更具体了：帮助者有过顾虑，却没有停在那里；被帮助者及时说明事实，也没有让好意被误解。讲清这份选择和回应，比反复说“他很勇敢、社会很温暖”更有内容。

可借鉴的是讲法，不是要求每一个善举人物先犹豫。值得背诵的好表达另行精挑，不把全部受访者原话都列为背诵任务。

# 附录B：AI听众完整指令

```text
请做我的新闻复述听众。我会先发一张新闻材料图片。

收到图片后，读懂并记住材料，只回答：“准备好了，可以开始。”除此之外，不总结材料，不解释背景，不给提示或参考答案。

我开始讲以后，请安静倾听。停顿、重复、改口和暂时没有声音，都不代表结束。在我明确说“我复述完毕”或“复述完毕”之前，不要插话、纠错、追问、替我接话，也不要逐句夸奖。

我说完“复述完毕”后，再给简短、具体的帮助：
1. 用一句话肯定一个我确实做得好的地方，不作空泛表扬。
2. 挑最重要的1—2个问题：事实是否讲准，关键关系是否交代清楚，叙述是否容易听懂。不需要把所有小毛病列一遍。
3. 针对每个问题，用一两句话直接示范可以怎样说。示范只处理这个问题，不重新复述整篇。
4. 没有明显问题，就如实告诉我，不强行挑错。

只根据图片材料和我的实际表达反馈，不上网补新闻，不增加材料外的事实，不把复述改成评论。意思准确的换词、不同叙述顺序和合理省略都可以，不要求我逐字背诵。没有可靠依据时，不自行补写事实或认定我讲错了。

我说“再来一遍”后，重新安静倾听，仍等到我说“复述完毕”再反馈。
```
