## 一、本轮任务及优先级

继续制作同一份口语素材周刊，不扩建雷达、不另编课程、不做学生 App，也不要求老师逐条整理原文或维护流程。

三个一级模块不变：

1. 复述：把新闻讲清楚。
2. 评论：依据已知材料形成观点，学习有内容的口语评述。
3. 原文拆解与积累：独立精选近期评论中的好段落，扩大观点、论据和语言积累。

这次的关键关系：**第一、二模块共享同一批题；第三模块另行独立选文，不围绕前两模块反复摘句。**

本文件是 v0.4 的合并修订版，优先于 v0.4、v0.3 及更早文件中的冲突要求。未变部分已保留在下文。以下旧要求明确作废：

## 二、模块一：复述——两页一题，答案集中

### 1. 选材与材料页

沿用约5—6则上周社会热点、3则暖文／正向社会生活材料的试制规模，不因旧稿已有成品而保留不适合的题。

**本轮撤换“教育部表态让老师身后有盾”这则复述题。**教师已多次明确认为它太抽象，不能再加一段笼统背景就算完成修改。同步更换第二模块里依赖该材料的对应评论，其他可用题目尽量保留。第三模块不是回收被撤题的地方。

优先选择能讲清人物或对象、发生了什么、怎样变化、有哪些细节、结果或回应的新闻。文化生活、青年生活、公共服务等现象题也可选，但需有具体表现或实例，不写成发布会举措清单，不编造主人公。

每题第一页：标题＋大字新闻材料＋简洁来源／时间＋短陪练提示。正文约16—18磅可作为试排起点，按真实版面调整。保留有意义的背景、经过、细节和变化。不是两行摘要放大成一页，也不为填满版面扩写情绪和评论。

事实必须来自可核对的材料。可以重组和叙述，不补写人物心理、现场对话、动机、动作或结局。引用当事人或媒体的评价时明确归属。收尾可以有轻微点题，但不能用连续设问、批评或宏大评价代替事实。

标题准确、直观、可读，不用晦涩比喻或未经论证的价值结论。

### 2. 提示页：保留关键词，重做思维导图与插画

**关键词网络**继续保留。它负责提示材料里有什么重要信息，使用短词，不复制整句答案。

**思维导图必须有真正的分叉层级。**先依据正文整理出完整的信息结构，再选择部分节点留空。中心是这条事件，主枝可以是人物／处境、具体行动、回应、结果等；次枝是归属于主枝的事实或关系。分支名称服从每条材料，不给所有题强套同一张图。

**这里要可视化的是材料的信息组织和关系，不是给文章做缺字测验。**可以出现人物与处境、行动与回应、变化与结果等层次；复述图不提前植入评论结论。过程关系可以放在其中一条分支里，但不能把整张图压成几个按时间排列的方框。

挖空的单位主要改为“一个完整意思”：一项做法、一种处境、一组结果，或者一小组相关分支，而不是一个词的一两个字。物理空间也要相应变大，允许写短语、分点，必要时写一两句；不是把原来的横线画长一点。

仅作版式示意，下面不是本期题目或标准答案：

```text
中心：这一事件
├─ 人物与处境
│  ├─ 人物／对象：保留必要提示
│  └─ 对方遇到什么困难：[整块书写区]
├─ 行动与反馈
│  ├─ 最初做法：给一个简短线索
│  ├─ 得到怎样的回应：[整节点书写区]
│  └─ 后续调整
│     └─ [保留分叉线，让学生补出相关做法或信息组]
└─ 结果与变化
   └─ [整块书写区，可分点填写]
```

正式图绘成树状或放射状。节点名称、分支数量和方向服从本条材料，不将示意变成每题固定模板。

留空要求：
- 主干、关键分类和适量提示保留，让学生知道需要补哪类信息；不要把全图挖成无从下手的白纸。
- 大空用于概括整项信息或补全一组关系，支持学生重新组织语言，不是只背原句。
- 空白在内容范围与印刷面积上都足够。整节点可留可书写空框或几行短线；分支组留出补节点的位置。不要挤成小小的括号。
- 不规定每题必须挖几个空、挖掉多少比例。根据材料难度调整；日期、数字的小空可以少量存在，但不能成为主要练习。
- 同页关键词可以提供记忆线索，但不要与待补节点逐字配对，变成照着另一张图抄答案。
- 合理同义表达和准确的信息重组都可接受。答案给关键要点与可接受范围，不要求逐字唯一；确需准确的人名、数字、时间单独核对。
- 所有待补内容在本题材料页中有依据，不让学生猜来源未提供的事实或提前抄后面的评论。
- 先完成整图，再产生留空版和答案版，两者来自同一份节点内容；把答案实际放回各空，检查逻辑、语义、位置均对应。

**插画须提供画面记忆，而不是第三遍文字摘要。**风格与协作方式见第三节。Agent 本轮主要负责写清画面需求、可直接使用的提示词和图片编号，随后接收外部生成的图片并整合排版。不要把程序绘制的喇叭、门、箭头三图标当作场景插画完成品。

关键词负责提醒信息，思维导图负责组织信息，插画负责唤起场景。三者不得重复同一份长摘要。

### 3. 集中参考答案

每题两页连续出现，全部题结束后进入“复述参考”。试排每页约三则答案，长题可两则，不通过缩小字体强凑三则。

每则用相同题号、标题和题页码定位，给自然连贯、以事实为主的参考复述；有必要时附简短导图填空参照。不要保留一题一页的大面积空白。

参考复述不要求逐字复刻，也不必一律更短。它示范事实取舍、叙述顺序和自己的表达。不能在后半段变成一篇短评，不新增未经来源支持的信息。教师已经允许最后少量点题，不必以绝对“零评论”机械删掉所有自然收束。

制作说明、“取舍”、版本、字数审核和编辑自评不印在学生页。

## 三、插画：提示词交接、这里出图、回传排版

本轮风格方向：**黑白报刊式叙事插画，简洁、有一点生活感和趣味，不幼儿化。**

统一参考描述：

> 白底黑线的报刊人物插画，线条清楚、粗细适中，人物神态自然，保留一两处有辨识度的动作、物件和必要环境；留白充分，主体关系一眼可辨。不要写实照片感，不要密集排线、大面积黑块、复杂灰阶、渐变或细碎背景，不要夸张的英雄化表情和低龄卡通比例。不把整段材料写进图中。黑白打印和缩放到提示页实际尺寸后，仍能看清主体及关键动作。

图像依据已核对的事实设计，标为示意插画，不冒充现场照片。一般性的背景简化不需要成为新闻事实；不得添加改变事件含义的行为、对白、结果或身份特征。救援题不把画面做成未成年人应模仿的操作教程。

可以是一幅场景，也可以有必要的少量分镜，不要求每题相同分镜数。图中的必要说明文字优先由排版程序另加，不依赖图像模型写精确中文。

### 本轮默认采用简单协作，不追求全自动

每周只有一期、少量插画，不为此安装复杂系统、维护登录会话或开发图像接口调度。具体流程是：

**Agent 定稿材料并写好插画需求 → 教师将需求包发到当前对话 → 在这里使用实际可用的图像工具出图 → 教师把图片交回 Agent → Agent 嵌入、检查、导出刊例。**

教师只需要转交文件和图片，不需要自行提炼事实、补写画面提示词或逐张研究排版。首次可以先用一张确认画风，再按同一风格完成本期其余图片；不要求每周重复搭建工具。

先把统一画风与出图要求整理成一份可复用的绘图说明即可。是否以后封装为专门工具，另行决定；本轮只需提示词和图片转交，不新增开发任务。

### Agent 应提交一份可直接交出的 `illustration-briefs.md`

开头给出本期统一画风与使用方式，随后逐图提供：

- **图片编号、对应题目与位置**：例如 R03-ILL01，对应复述第3题提示页；预定横纵比例、实际放置区域大小、拟保存文件名。
- **定稿材料全文或足够完整的事实摘录**：出图端不应被要求仅凭题名猜新闻，也不能只给一个无法读取的数据库ID。附简洁来源供必要核对。
- **本图帮助记住什么**：本条材料中特别值得看见的场景或人物／物件关系，不先设计装饰再找用途。
- **画面方案**：谁在什么位置、做什么，哪几个物件必须可辨，背景保留到什么程度。一幅场景足够就不画多格。
- **必须保留与不能添加的内容**：尤其是事实数量、角色、行动和结果；一般服饰、环境可做不改变事件意思的简化，不虚构原话和新情节。
- **可直接复制的完整绘图提示词**：将统一风格和本图情境合在一起，不让教师再次整理；无需指定未经确认的模型名称或参数。

一份 Markdown 加实际图片文件即可；不要再提出图像任务数据库、复杂清单协议或审核后台。

### 图片回传后的工作

图片到达后按题号／图片编号关联，保存到本期资源目录，替换预留插画区域。Agent 检查事实、画面可辨性、裁切和黑白缩放效果，再导出正式 PDF。文字标签优先由排版层补，不要求图像模型生成大量准确中文。

缺图时继续完成新闻、评论、导图和排版准备，先交“文字与导图完成、插画待回传”的审阅稿及需求包。这是本轮正常的阶段性交付，不是采集或写作失败。未收到图时，不以图标冒充插画，也不宣称完整版已经完成。

若既有环境本来就有现成、已授权的出图能力，可以使用，但不把寻找或配置新通道作为本轮任务，也不改变默认可用的转交方案。

## 四、模块二：评论——先留思考空间，再展示推演与范本

评论题继续从本轮复述里选，约3则热点、3则暖文或正向社会生活材料。前两模块同题，第三模块独立选材。

### 1. 思考与参考内容在纸面上分开

每题先有独立的思考页，回指复述材料页，并用少量关键事实唤起记忆。单独导出评论册时附简短题干，不能依赖另一分册才能理解。

提出真正帮助进入材料的问题，给适度书写／圈画空间。不要问题下一行立刻给答案，不要求学生必须写完才能翻页，也不要求无监督学生先完成两分钟自主作答。

问题数量随材料而定。它们可以引导注意细节、换视角、追问原因、比较不同理解或联系生活，不应提前制造虚假事实和对立。例如没有报道其沟通经历，就不把“为什么他已与家长沟通无果”当成既定事实提问。

参考观点、推演、范本和拆解从下一页开始。内容多可以延伸，不为了硬塞两页而再次写薄。思考页和答案页不得排在同一张可同时看到的跨页上；实际装订方向不确定时，明确留出遮盖或翻阅方案。

### 2. 问题与观点相辅相成，不一一配答案

取消“对应问题1／2／3”的固定模板。

一个问题可能打开多种观点，几个问题也可能共同支持同一观点。参考部分应整理成几条有区别、可继续展开的理解，不把所有观点塞进同一篇范本。

可用一行说明初步感受，但不以“气愤”“很感动”代替后面的判断。

对最有价值的思路，用一小段读得懂的讲解展示怎样推进：从材料的具体信息出发，先发现什么关系，再追问或检查什么，最终得到怎样的判断；必要时说明这条判断没有证明什么。不要只写“细节：某动作，所以体现某精神”。

这些是面向学生的讲解，不要求每条都套固定四步表格，也不能把自然思考写成能自动算出观点的公式。

例：按当前材料，魏治立先制造声响，回应少后改为逐户示警。
可展示的推演是：发出提醒不等于熟睡的人已经收到；改变提醒方式，是在设法使具体住户真正察觉危险；因此，帮助的价值还体现在对实际效果的持续关注。
这只是编辑示意，不要求全篇照搬，更不能由此补写当事人未被报道的心理活动。

### 3. 媒体评论的借鉴要落实到理由和语言，不只提到来源

有适合的原评论时，先取得完整正文，理解作者回应的具体问题、立意、论据、解释过程、限制条件和有效表达。多篇讨论同一事件时，可以比较角度，但不为凑数强求多篇，不虚构分歧。

**借鉴不是降低写作要求的理由。媒体评论是原料，教师的教法才是本项目范本的组织依据。**读过一篇好文章，不代表借出来的口语稿已经写得好；素材来源齐全也不等于论述合格。

借鉴时保留原文中确实成立的观点、关键理由、案例和好表达，再做以下调整：
- 提取本题真正要回答的问题，选定一条可以在短时间内讲清的主线；不把多篇原文的所有角度拼进一篇。
- 开头直接给判断，以合适的关联词说明两层意思的关系，不照搬媒体铺新闻、慢慢入题的导语。
- 两个主体段各有自然、可说出口的小观点，解释与材料共同支撑它；保留必要的“为什么”，不只摘头尾金句。
- 段落之间的关系真实成立，结尾回到主线；不能原文怎么分段，我们就怎么分段。
- 保留好的原句、准确限定和学生自然表达，也允许有分寸的修辞。口语化不等于改成闲聊、降低语言质量，或者让所有句子都变短。
- 原文有局限就不采用相应判断。不能因为它是媒体原文，就替其夸大、跳步或不适合本题的对照背书。

学生版只呈现成品、必要来源和有价值的学习内容，不增加“模型读了什么、如何取用、用了什么工具”的制作说明。

教师备注中简短写明：
- 实际读到哪篇评论全文；
- 采用了哪条观点／解释／表述，进入范本哪一段；
- 为适配口语结构作了什么调整；
- 没有参考评论时明确写独立分析，不把新闻报道冒充评论来源。

这些仅是编辑内部的简短记录，放在 `editor-notes.md`，不变成给学生的新栏目或作业。一个小记录写清“来源 → 取用内容 → 用于哪段／如何重组”即可，不要求逐句标注借鉴，也不用新增数据库或复杂溯源平台。没有足够依据说“借鉴得好”时，不以来源数量给成稿贴优质标签。

### 4. 暖评先把思考展开，再写成范本

本轮暖评不是一般润色任务。先解决“除了赞美，还多看见了什么、解释清了什么”，再处理句式和语言。不能只把“不是……而是……”换成“既……也……”，原有空泛判断却原封不动。

教师已经讲过的读细节、读关系、基准线后继续追问、联系生活、转换视角与找靶子，必须真正用于材料处理。它们是可选工具，不是每篇必须完成的步骤表。

选取最有解释力的一个或几个入口，视材料展开，例如：
- **对谁的处境有改变**：改变在哪里，为什么这一小变化对当事人重要；不只重复“受到帮助，所以感动”。
- **一个行动如何起作用**：行动经过什么中间环节产生效果，有哪些必要条件；不只把动作与结果并排。
- **不同角色之间是什么关系**：除了职业、身份标签，还能看到哪些具体需要、回应和相互作用。
- **一件小事让我们重新认识什么**：评价职业、理解公共空间、看待个人选择的标准是否多了一层；不为了上升而生硬切到制度建设。
- **现象为何值得注意**：从物质变化走到生活方式、选择或关系的变化，必须讲出连接过程，不添加未经支持的宏大结论。

不是每篇都要往外拓展很多社会议题。先在本题内部把关系讲透，再选择真正有依据的更一般理解。可以有感情、联想、生活经验、对照与合理推断，但不补写新闻人物的经历和心理，也不为一项善举强找坏人作陪衬。

课堂中的方法参照（只说明期待的思考深度，不替本期选题）：
“归还手机后主动请求好评”这道题，不能只停在拾金不昧。还可以留意为什么材料特别写“主动请求反馈”、投诉与好评为何不对称、把认可反馈到店里对服务者有什么意义，进一步从单纯的职业标签走到帮助者与被帮助者之间的关系。实际稿件必须区分题干事实与可能的解释，不能把课堂讨论中提出的心理推测都写成已证实事实。

输出的推演应是学生读得懂、能跟着往下想的一小段讲解：把支持观点的事实和关键推导说清楚，不以工作日志或固定步骤标签代替论述。每次往前都要增加一个原因、关系、条件或判断，而不是同一个意思换几个词。

若暖评仍然单薄，应重新读完整材料、重选立意或重写论证，不只加形容词和结尾口号；也不能为了避免犯错，把所有解释都删成谨慎的新闻复述。完成有根据、有增量的思考后，再由合适的写作模型把它组织为自然、成熟的口语范本。

### 5. 所有范本仍执行同一套表达标准

- 第一处表达就给具体判断，可以带最少的材料指代，不再长篇介绍事件。
- 主体默认两段，每段开头是可以说出口的小观点；后面有解释、推演和恰当的事实依据。
- 两段必须说不同的内容，共同服务同一主线；结尾独立收束，不让后几篇写着写着只剩一句判断和两段故事。
- 不能把整个事件搬到主体里，再说已经避免开头复述。
- 观点可以做价值判断、原因分析、关系辨析或举措建议。暖评不强制写成“个人善意＋制度托举”，也不靠与一个虚构的坏人／落后做法对照来显得深刻。
- “不是……而是……”仅在有必要纠正某种理解时使用，不能成为每篇的默认开场。不用禁词清单替代判断，但没有对象可否定时要改成立得住的正面表达。
- 不强求反直觉金句。把熟悉的善举说具体、解释清楚，也可以是好评论。
- 感情可以保留，语言需要自然、有节奏、有质感，但不能变成低幼赞美、套话或反复闲聊；不模仿助手此前生涩的改稿措辞。
- 既不能凭空编造事实，也不能把“合理推断”完全取消。区分已报道事实、根据事实提出的解释，以及明确的假设／建议。
- 学生已经提供的真实案例，不因编辑暂未补齐出处而擅自改成虚构设想；核对记录与作者原意分别保存。
- 不以单次救援成功的结果，教学生照搬危险行为；不将身体障碍当成没有能力或只有被帮助资格的同义词。

本轮可以换用已有且实际可用的写作模型试写暖评；沿用既有任务流程，不开发模型平台。不得声称调用了未实际使用的模型。若没有其他可用模型，如实说明，不把同一篇旧稿仅换几个同义词当作重新写作。

### 6. 先审范本，再做拆解

拆解不负责赞美自己生成的稿。说明具体小观点如何被理由和材料支撑，选出真正有价值的词语、句段及其作用。发现原稿推不动，应先改原稿，不能用“很有力量、层层递进、反直觉”替它背书。

同时检查两个方面：一是思考与论证有没有真正多说清楚一点，二是表达是否符合教师要求且自然有质感。仅有四段格式不算完成，仅有流畅修辞也不算完成。助手此前的村咖改稿只提供结构参照，不是必须仿写的语料范本。

按全部六篇检查质量，不能前三篇饱满、后三篇明显缩水。记录真实字数与实际朗读情况；没有真人／可验证朗读，就不要声称精确达到两分钟。

## 五、模块三：独立的近期评论原文精选

### 1. 重新选文，不再围绕本期八道题拆七次

从已有评论来源近期的完整文章中独立浏览、精选，关注哪里真正写得好。优先本期前后几周的文章，必要时适度放宽并注明日期，不把“积累素材”伪装成本周新发生的事。

本轮第三模块重新选材，不沿用“红星教师三段＋病历两段＋葫芦两段”的七条凑数方式，也不把匹配前两模块题目作为筛选条件。本轮优先选择前两个模块以外的话题与文章，避免学生翻到这里还是同样几件事。先独立阅读、找到完整而精彩的段落，再决定教学标签，不按“开头两句、主体两句、结尾一句”填空凑数。

这里要看的是近期评论作者还在关注什么、怎样思考和表达，让学生拓宽视野。不是给第二模块列素材出处，也不是第二模块写作过程的附录。独立选文与第二模块借鉴评论是两回事。

可以从浙江宣传、现有评论频道的其他媒体中选，但不预先假定某栏目必有好段。若本地只有标题或摘要，按需补取拟选文章全文；不需要先清空全库积压，不另建采集网络。

### 2. 选的是完整、有内容的段落，不是金句合集

选择约6—7个学习单元，以一段完整自然段或必要的连续两三段为主体。选段以能够看见一次论证、描写、举例、转折、递进或收束为准。

可先将约150—400字作为试选参考，长短服从段落完整性，不是新的字数配额。短句可以作为段内重点圈出，但不再让一句“最好的场景就在那儿”单独占据主要学习单元。

不为了凑“两个开头、两个主体、一句金句”等分类而牺牲段落质量。数量不足时如实说明，不用空泛短句补满。

### 3. 每单元如何呈现

**新闻背景与作者问题**：说明这篇文章因何而写、片段回应什么问题；交代够学生在纸上读懂即可，不只是写“接在全文第二部分之后”。

**真实原文**：印出选中的完整段落，保留作者、媒体、日期和出处。删节要标示，不把不同位置拼成假装连续的原文。不把AI仿写标为媒体原文。原文归属未确认的不要进入署名精读。

**重点拆解**：针对这段真正有价值的地方，解释句间如何推进、案例怎样进入观点、词语为什么准确、哪里形成转折等。无需逐句贴标签。可以用少量标号、划线或旁注回指原句。

**积累与使用**：说明值得记什么、可以支持哪一句具体判断、用在主体说理／案例衔接／开头／结尾哪个位置；给一段实际可用的衔接或改写示例。若是换题，必须说明相通的关系，不能仅替换人名或名词。

原文中本来适合口头表达的段落可以直接熟读或背诵；不为了“口语化”强行改坏。不要求每段都有跨题仿写，没有自然适配场景时，可以示范如何摘取、压缩或嵌入本类议题的表达。

书面评论的开头可以先叙事，但移入口语范本时仍遵守本项目观点先行。不能把“媒体这样开篇”直接教成“考场也要先铺一段新闻”。

## 六、AI陪练指令：读材料、当听众、听完再帮

这是有设备时的附加用法，纸面资料仍然可独立使用。不要开发新App，也不要替每道题另建专用机器人。

材料页脚放简短提示，并提供一份完整可复制文本，避免用户只能从整本最后一页手抄。可放在目录后的简短用法处，不增加很长的课程说明。

完整提示词建议：

```text
请做我的新闻复述听众。我会先发一张或几张新闻材料照片。

先读清材料。看不清的地方只问我具体哪一处，不要猜。读清后只说“准备好了，你可以开始”。不要提前总结、复述材料，也不要给参考答案。

我开始讲以后，以倾听为主。我停顿、重复、改口或暂时没声音，都不代表结束。没有听到我明确说“我复述完毕”之前，不要插话、纠错、追问、接着替我讲，也不要逐句夸奖。

听到“我复述完毕”后，才给简短、实用的帮助：
1. 先用一句话指出我讲清楚的一点，不作泛泛表扬。
2. 优先指出最影响听懂的1—2个问题：事实讲错了、关键关系遗漏了，或顺序令人困惑。说明我说的哪里需要调整、材料实际是什么。
3. 针对问题，用一两句话示范怎样补充或重说。不要一上来再讲一篇完整答案，除非我明确请求。
4. 没有明显问题就如实说，不为了显得专业硬挑毛病。

意思准确的换词、不同叙述顺序和合理省略都可以。若是你没听清我的话，要先确认，不要当成我讲错新闻。
只依据我发的材料反馈，不上网补新的事实，不把复述改成评论，不强迫我逐字背诵。

我说“再来一遍”时，重新进入倾听状态，仍等到“我复述完毕”再反馈。
```

这是期望的互动规则，不是对任何语音产品自动轮次控制的保证。若实际产品自动插话或无法跨看图与语音环节保存材料，记录具体限制；未实测就注明未实测，不能靠一段提示词声称全流程已经通过。

## 七、制作与审核方式：少交新规划，多改实际稿

先固定拟采用的事实材料和原评论，再做观点、范本与拆解；内容确定后制作导图、插画需求和版面。图片按第三节从外部回传后再整合。不要让全文压缩、提示图、答案和拆解各自随意补写不同版本的事实。

复述首题替换后，同步更新评论、目录、提示、答案、第三模块中的相关应用例子和教师备注。不要旧题已经撤下，使用示例还声称它是本期材料。

先在内部验证一个“材料＋整块留空的分叉导图＋集中答案”的内容关系，再完成其余题目；同时将定稿材料的插画需求整理成一个文件交出。无需等图片返回才继续写评论和选原文，也不要求老师逐页审批。图片回传后再核对一个实际印刷单元，继而整合全刊。

重点检查：
- 材料能否独立读懂；复述是否以事实为主。
- 思维导图是否真有分叉与层级；是否主要留出完整节点／信息组而非一两个字；书写面积是否匹配；回填语义是否准确、有材料依据并接受合理概括。
- 答案集中放置后，题号、页码与跳转是否对应；两三则答案一页是否仍好读。
- 评论思考区是否与参考内容分开；多个问题与观点是否仍在机械配对。
- 无论有无参考评论，范本是否遵守教师的观点先行、两段论述、合理关联与结尾收束；暖评是否有真实的连续解释与思考增量，而不是故事加抒情、概念替换或虚构对照。
- 借鉴说明是否仅留在教师备注；第三模块是否另从近期评论独立精选完整好段，是否拓宽题材，原文、拆解和应用是否一致。
- 插画需求包是否自足、可直接用于出图、每幅图有稳定编号与位置；回传后是否实际嵌入真实图片，适合黑白实际尺寸打印，未增加改变事件含义的情节。
- “9月4日＝教师节前一天”、未经来源支持的医疗恢复时长、不同统计口径硬对比等已指出问题不能遗留到图示、答案或旁注里。

不以“全部检查通过”的宣告代替真实检查。把尚未解决的事项放在教师备注，不把它们包装成正式完成。

## 八、交付：文字先完成，图片回传后整合

目标目录仍为 `weekly/sample-01-rev3/`。不另开大型开发任务，不因为插画采取人工转交，就让文字工作停下来。

### 第一批：Agent 可以独立完成的实际内容

- 修订后的学生版 `sample.md`、可修改排版源文件，及已完成的关键词图、整块留空导图、对应答案；
- 便于看版面的审阅 PDF。图片未返回时明确标为“插画待整合”，不要当作最终发行版；
- 一份 `illustration-briefs.md`：统一风格＋本期逐图事实与完整提示词；
- `editor-notes.md`：简短借鉴说明、来源与未决项、实际使用的写作工具、朗读与语音陪练实测状态；
- `change-summary.md`：说明本轮哪些内容实质改变，哪些图片待回传；
- 沿用可复制的陪练提示词文本。

第一批不能只有计划、空模板或待制作栏目。图片可以待回传，复述、评论、独立原文学习的文字要真正改好。

### 第二批：图片回传后

Agent 按既定编号将图片嵌入资源目录，检查裁切、分辨率、黑白效果、图文对应与页码，重新导出完整 `sample.pdf` 及三模块分册。复述分册包含自己的集中答案。只有真实图片整合后，才将插画状态改为完成。

不要求新增图片管理软件或自动化服务；现有排版脚本能读取图片即可。保留图片需求文件，便于下期复用与风格统一。

学生版只保留刊名、自然期号／日期、简洁目录、题号、页码、必要来源和学习内容。不放 rev 号、规范版本、模型借鉴日志、生产自评或固定步骤框。课堂记录和学生姓名不提交公开仓库。

按项目既有流程保存与推送，每批给出实际成品入口，简短汇报：
- 热点一换成了什么，复述答案如何集中；
- 整块留空导图怎样帮助组织信息；
- 暖评在思考和论证上具体改进了什么，而不只汇报换了哪个模型；
- 第三模块独立选了哪些文章和完整段落；
- 插画需求包在哪里、哪些图片待回传／已整合；
- 尚未解决的来源或实测问题。

不要为了等待图片而重启全项目规划，也不要把“需求包已交出”写成“插画已完成”。
