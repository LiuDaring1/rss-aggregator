# 交接参考包｜先读这里

这是给 ZCode 执行整套项目交接的**任务书与参考资料包**，不是已经从用户电脑复制完成的项目备份。

## 用户的使用方式

把本包下载、解压，让 ZCode 读取 `00_ZCode_打包交接任务书.md`，按其要求在桌面建立完整的“口语素材周刊_Antigravity”接手目录。

ZCode 负责从实际本机工程复制代码、数据、配置和生成流程。本包负责补齐教学原件、历史要求和本次最新澄清，避免新 Agent 只看成稿、不知道教法。

完成后，把桌面交接总目录添加到 Antigravity 项目中，选择 Local，在新会话使用 `01_Antigravity_首次接手指令.txt`。首次先读交接入口，不自动启动采集或重写整本。

## 文件职责

- `00_ZCode_打包交接任务书.md`：给原 Agent 的实际打包、说明和验证任务。
- `01_Antigravity_首次接手指令.txt`：给新 Agent 的开场指令。
- `02_当前产品与编辑要求.md`：当前要求。ZCode应复制为目标目录的 `CURRENT_REQUIREMENTS.md`。
- `03_参考资料索引.md`：哪些原始文件已经随包提供，以及处理边界。
- `references/teaching-private/`：教师提供的教学原件，保持原始文件，不作改写。
- `references/historical-briefs/`：旧任务书及AI听众指令，仅供查阅。与最新要求冲突时，以最新为准。

## 最重要的内容澄清

**观点页需要多个有区别的思考方向；只有最终范本才选择一条主线，以两个主体段展开。**

不要继续把“两个主体段”解释成“只能提供两个参考观点”。

## 私密资料说明

本包含原始课堂记录、学生姓名和课堂反馈，只供用户与获准的本地 Agent 接手使用。不要将整个参考包或教学原件提交到公开 GitHub。公开示例需另行匿名化。

本包不含用户本机 API 密钥、登录态、数据库或完整工程；这些只能由 ZCode 在用户本机按任务书盘点、备份和验证。包中没有复制系统字体文件。
