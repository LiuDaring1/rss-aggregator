# 口语素材周刊 · 项目规则（生产定标版）

1. 目标：为高中播音艺考生维护可打印的《口语素材周刊》（复述 / 评论 / 原文拆解与积累三模块），采用教师认可的自然青年口语示范标准进行日常生产。
2. 最新编辑要求入口：交接目录根的 `CURRENT_REQUIREMENTS.md`（现行唯一有效规范，不在本文件内重复展开）。
3. 结构与立意约束：
   - 观点与推演页尽可能充分给出多个（3~6个）有区别、有依据的思考方向，不设固定上限；
   - 最终口语范本围绕选定的一条主线展开两个主体段（主体段内容由该题主线决定，绝非千篇一律套用特定公式）；
   - 修辞（比喻、排比、对仗等）贴合情境自然使用，不作为篇篇必用的死规矩。
4. 双工作区职责与数据通路保护：
   - 原工作区 `~/Desktop/RSS订阅-zcode`：常驻 RSSHub (:1200) 与聚合站 (:3001) 服务，作为天天正能量 (aggr-site/data/wenwen/) 的唯一写入源；保持后台运行，不得随意终止；
   - 本工作区 `~/Desktop/口语素材周刊_Antigravity/project`：负责评论持久化 (aggr-site/data/commentaries/)、候选池扫描 (prep.py)、内容采编与离线构建 (cli.py build)；
   - 两工作区通过软链接共享 live 数据，避免多服务争写同一目录；构建与核验保持 100% 确定性离线，无网络/模型依赖。
5. 门禁与真实性底线：
   - 前置门禁：入选原文拆解必须归档真实原件，且引文段落必须与存档原文 100% 连续精确匹配；
   - 后置门禁：生成的合订本与各分册物理页数必须与动态规划完全吻合，杜绝跨页截断与空白溢出；
   - 历史复用明示：往期已用材料若入选当期，必须显式标注复用标记与理由，绝不伪装为当周首发。
6. 私密资料保护：`references/teaching-private/`、`_private/`、`aggr-site/ai.json`、`we-mp-rss/config.yaml` 严格本地保留，绝不提交公开仓库。
