# 口语素材周刊 · 项目规则（简版）

1. 目标：为高中播音艺考生维护可打印的口语素材周刊（复述 / 评论 / 原文拆解与积累三模块），当前审阅基线为 `weekly/sample-01-rev5/`，尚未获教师内容定稿。
2. 最新编辑要求入口：交接目录根的 `CURRENT_REQUIREMENTS.md`（不在本文件内重复展开）。
3. 两个不可混同的任务：观点与推演页尽可能充分给出多个有区别、有依据的思考方向；最终口语范本才从中选一条主线，用两个主体段展开。不要因范本有两段就只给两个观点。
4. 原目录保护：原工作区 `~/Desktop/RSS订阅-zcode` 与其运行中服务（:3001、:1200）不得写入或停止；本副本验证用独立端口与 `AGGR_AUTOTASKS=off`。
5. 私密资料：`references/teaching-private/`、`_private/`、`aggr-site/ai.json`、`we-mp-rss/config.yaml` 不提交任何公开仓库。
